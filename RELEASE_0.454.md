# Bubbsun 0.454

Den här versionen samlar den godkända supporter- och designuppdateringen:

- kompakt bildlogga med sloganbanderoll och valbar Fancy Glow
- bredare temaväljare med tydligare vald-markering
- 16 nya listikoner, varav fyra supporterexklusiva
- Retro Candy-färger för listor
- fyra Celestial-färger för supporterprofiler
- Founding Supporter-märke på Om-sidan

Låsta supporterikoner, färger och teman visas nedtonade med lås. Befintliga sparade val bevaras.
