# Bubbsun v0.470

This is a large statistics, navigation and interface update.

## Highlights

- An intentionally playful statistics dashboard with summary cards, bar and line charts, user distribution, records, streaks, averages, top items and shopping-cart facts.
- Correct hierarchical physical-back navigation throughout the app.
- The supporter exploration button now opens Settings at the supporter controls.
- Translated Versions & News navigation while patch notes remain consistently in English.
- Restored the approved compact My Lists tab connected to the header.
- Dynamic Bubbsun logo positioning based on whether a supporter decoration is visible.
- Richer static Cosmic and Heartfelt theme backgrounds without additional battery use.
- More compact list, product and settings forms.
- Refined About-page portraits, version icon and clickable Founding Supporter badge.
- A dark Bubbsun system splash screen with no artificial delay.

Existing lists, users, supporter choices and statistics remain compatible.
