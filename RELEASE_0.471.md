# Bubbsun v0.471

This release focuses on reliability, readability and small interface refinements.

## Highlights

- Optional background update checks against GitHub Releases, with direct APK and release-page links.
- Large Download, Not now and GitHub actions on the update page.
- Fixed the Exit Bubbsun action and made the side menu scrollable on smaller displays.
- Locked in-app typography to Bubbsun's intended scale regardless of Android font-size settings.
- Added new illustrated Daniel and Sanja portraits based on the creators.
- Unified back, edit and delete controls in the approved retro icon style.
- The same delete icon is now used consistently throughout the app.
- Cleaned and re-centered the Fire theme and supporter shopping-cart artwork.
- Made completed items noticeably grayer while preserving readability.
- Added compact name and balance-scale icons inside product inputs.
- Swapped About-page action colors: suggestions are positive green and problem reports are muted red.
- Improved contrast on playful statistics cards.

Existing lists, users, supporter choices, statistics and settings remain compatible.
