# Bubbsun v0.472

This is a small visual hotfix for v0.471.

## Changes

- Replaced the thin program-drawn back, edit and delete symbols with polished illustrated retro icons.
- Added the selected teal-and-coral Heart supporter shopping cart.
- Tightened spacing between product-field icons and text in both Add Product and Edit Item.
- Gave the optional quantity placeholder more room on narrow phones.
- Made completed-item names and quantities clearly grayer.

All data and settings remain compatible with v0.471.
