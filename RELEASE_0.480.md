# Bubbsun v0.480

This is a major feature release focused on finding things faster, collaboration groundwork, help, feedback and small-screen polish.

## Changes

- Added a right-edge Search & Sort drawer to every shopping list.
- Added live substring search with separate active and completed results.
- Added Custom, A–Z, Z–A, newest and oldest sorting without overwriting manual order.
- Added independent completed-item placement and saved Done-section state per list.
- Added per-user NEW badges, new-item counts and future sync-ready read tracking.
- Added live `left • done` list status.
- Added an offline, searchable Help & Guides page and first-use sorting tip.
- Added private in-app problem and suggestion forms through Formspree.
- Added a manual update-check button and smarter startup reminders.
- Improved narrow-screen titles, menu labels, product-field proportions and update-page contrast.
- Added the hidden Daniel and Sanja spinning, bouncing and heart-cloud Easter egg.

Existing lists and settings are migrated automatically.
