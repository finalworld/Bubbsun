# Bubbsun v0.500 • Together Edition Beta

Together Edition introduces accounts, family groups and real-time shared lists.

## Highlights

- Google sign-in with automatic return sign-in
- Firestore-backed real-time sync with offline support
- Create a group or request access with a short family code
- Owner, admin and member roles with server-enforced permissions
- Approval queue and automatic conflict-free member colors
- Safe migration choices for existing local lists
- Creator color markers on both list cards and items
- Per-user NEW markers connected to real family members
- Synced activity and statistics groundwork
- Ten-language expandable selector
- Updated Help & Guides, feedback forms and update status
- Together Edition privacy and account foundations

This is a beta release. Keep a copy of important lists while family sync is being tested.
