# Bubbsun 0.701 – Web Edition

Android-appen öppnar nu den aktuella Bubbsun-webbappen på
`https://www.bubbsun.se/beta/` i stället för den äldre Firebase-adressen.

- Samma Bubbsun-version på Android och webben.
- Framtida webbuppdateringar visas direkt i Android-appen.
- Kan installeras ovanpå Bubbsun 0.700 utan att molndata påverkas.
